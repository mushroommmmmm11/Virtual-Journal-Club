# Virtual Journal Club

A multimodal, voice-first virtual lab meeting for scientific paper presentations.

This repository is being bootstrapped with a runnable v0.1 that supports:
- PDF upload and text extraction
- Paper-aware discussion context
- Voice input in the browser via Web Speech API when available
- PI / ML Reviewer / Biology Reviewer / Statistician / Reviewer #2 roles
- Moderator-based speaker routing
- Presentation, Defense, and Journal Club modes
- OpenAI-compatible LLM backend
- Text-to-speech in the browser
- Markdown meeting export

See the setup instructions in this README after the v0.1 branch is ready.
